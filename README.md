# Nagar-Raksha: Hospital Edition

**Nagar-Raksha** is a smart hospital cybersecurity simulation project developed for Cyber Samvad Hackathon 2026 under Problem Statement 4: Smart City and Critical Infrastructure Cybersecurity.

## About the Project
The project simulates cyberattacks on critical hospital-related services and demonstrates how risk prioritization, safe fallback modes, and recovery procedures can help maintain service continuity.

## Key Features
- Simulated cyberattack alerts and risk scoring
- Monitoring of critical infrastructure assets
- Safe fallback and incident response actions
- Configuration integrity verification using SHA-256
- Incident logging and recovery simulation

## Technologies Used
- Frontend: HTML, CSS, JavaScript
- Backend: Python, FastAPI
- Database: SQLite

## Project Status
Developed as a cybersecurity hackathon prototype for educational and demonstration purposes.
